# [00] 구조

InstaDM은 Instagram 웹(`instagram.com/direct`)을 Electron 창에 띄우고, 새 DM이 오면 화면 오른쪽 아래에 카카오톡식 팝업을 띄우는 Windows 데스크톱 앱이다. 비밀번호는 저장하지 않으며, 로그인 세션은 `persist:instagram` 파티션에 유지된다.

## 파일

```
insta-dm/
├─ src/
│  ├─ main.js              메인 프로세스: 창·트레이·팝업·IPC·설정·로그 전부
│  ├─ titlebar.html        메인 창 위쪽 36px 커스텀 타이틀바 (설정·최소화·최대화·닫기)
│  ├─ titlebar-preload.js  타이틀바 ↔ 메인 IPC 다리
│  ├─ preload.js           Instagram 화면(igView)에 붙음: Notification 가로채기, 제목 (N) 감시, 목록 사진 클릭 가로채기
│  ├─ watcher-preload.js   숨은 감시 창에 붙음: 받은편지함 데이터/화면을 읽어 새 DM 감지
│  ├─ popup.html           오른쪽 아래 알림 팝업 화면
│  └─ popup-preload.js     팝업 ↔ 메인 IPC 다리
├─ assets/                 icon.png(앱), tray.png(트레이), badge.png(작업표시줄 빨간 점)
├─ scripts/make-icon.ps1   아이콘 생성 (npm run icon)
├─ docs/                   이 문서들 ([NN] 제목.md)
└─ AGENTS.md               코드 작업할 때 지킬 규칙
```

## 창 구성

| 창 | 만드는 곳 | 내용 | 보이는가 |
|---|---|---|---|
| 메인 창 `mainWindow` | `createMainWindow` | 테두리 없는 창. 창 자체는 `titlebar.html`을 그림 | 예 (닫기 = 트레이로 숨김) |
| └ `igView` (`WebContentsView`) | 같은 함수 | 타이틀바 아래 영역에 Instagram 웹, `preload.js` | 예 |
| 감시 창 `watcherWindow` | `createWatcherWindow` | 1280×900 받은편지함, `watcher-preload.js` | 아니요 (설정 → 감시 창 보기) |
| 팝업 | `showPopup` | `popup.html`, 최대 4개 쌓임, 5초 뒤 사라짐 | 예, 포커스를 가져가지 않음 |
| 로그인 창 | `igView`의 `setWindowOpenHandler` | 페이스북·Meta 로그인 팝업 (같은 세션) | 필요할 때만 |

`mainWindow.webContents`는 타이틀바이고, Instagram 페이지는 **`igView.webContents`**다. 페이지 이동, 새로고침, 확대 같은 작업은 모두 `igView` 쪽에 한다.

`igView` 위치는 `resize`, `show`, `restore`, `maximize`, `unmaximize` 때 다시 맞추고 `invalidate()`로 다시 그린다(흰 화면 방지). 렌더러가 죽으면 1초 뒤, 메인 프레임 불러오기가 실패하면(`-3` 제외) 30초 뒤 다시 불러온다. igView는 `backgroundThrottling: false`다. 창 가림 계산은 끄지 않는다([02] 알림 구현 원리.md의 주의할 점).

## 새 DM 알림 흐름

자세한 판정 규칙과 예시는 [02] 알림 구현 원리.md에 있다.

```
[감시 창] watcher-preload.js
   ├─ 1순위 checkInbox → /api/v1/direct_v2/inbox/ → processInbox
   │     · 시작 시 읽은 항목은 seed만 하고 알리지 않음 (seededAtUs = 그때 가장 최근 메시지 시각)
   │     · 내가 보낸 것 / seededAtUs 이전 / last_seen_at 이전 → 제외
   │     · dm:notify (source: api) + dm:unread-api (DM만 센 읽지 않은 대화 수)
   └─ 2순위 scanDom (API가 3분 넘게 실패할 때만 알림)
         · 줄마다 종류를 정함: 입력 중 → typing, 굵은 글씨(읽지 않음) → msg
         · 대화마다 종류가 바뀔 때만 → dm:notify (source: dom). 입력 중 팝업 뒤 실제 메시지 팝업이 다시 뜸
           (notifiedRows: 이름 → 종류, 읽음이 되면 지움. 미리보기 시간 글자는 계속 바뀌어 기준으로 쓰지 않음)

[igView] preload.js
   ├─ Notification / showNotification 가로채기 → dm:notify (source 없음 = page)
   └─ 탭 제목 "(N)" → dm:unread

[main.js]
   ├─ dm:notify: page 알림은 API가 정상이면 버림, 아니면 url·tag에 direct가 있을 때만 통과
   │            → resolveAvatar(로그인 세션으로 프로필 사진을 data URL로) → showPopup
   ├─ dm:unread: 제목 깜빡임 대비. 증가는 1.5초, 감소는 5초간 그대로일 때 반영 → 감시 창에 watcher:check
   └─ badgeCount = API 정상이면 min(DM 수, 제목 수), 아니면 제목 수
        → 트레이 툴팁, 작업표시줄 배지, 타이틀바 알약
```

팝업을 띄우지 않는 경우: 설정에서 알림이 꺼져 있을 때, 메인 창을 보고 있을 때, 같은 `제목|내용`을 10초 안에 다시 보낼 때.

## IPC 채널

| 채널 | 방향 | 용도 |
|---|---|---|
| `dm:notify` | preload·watcher → main | 알림 요청 `{id,title,body,icon,tag,url,source}` |
| `dm:unread` | preload → main | 탭 제목 (N) |
| `dm:unread-api` | watcher → main | DM만 센 읽지 않은 대화 수 |
| `dm:click` | main → preload | 팝업 클릭 시 페이지 알림의 onclick 실행 |
| `dm:avatar-click` | preload → main | 목록 사진 클릭을 가로챈 시각 (스토리가 열리면 되돌리는 안전망) |
| `watcher:check` / `watcher:status` | main ↔ watcher | 즉시 확인 요청 / 상태 기록 |
| `watcher:selftest(-result)`, `watcher:dump(-result)` | main ↔ watcher | 알림 경로 점검, 진단 파일 저장 |
| `popup:click` / `popup:close` | popup → main | 팝업 클릭(대화 열기) / 닫기 |
| `titlebar:minimize·maximize·close·menu` | titlebar → main | 창 버튼, 설정 메뉴 |
| `titlebar:state` | main → titlebar | `{unread, maximized, focused, theme}` |

## 설정·로그

- 설정: `%APPDATA%\insta-dm\settings.json` (`notify`, `sound`, `preview`)
- 로그: `%APPDATA%\insta-dm\insta-dm.log`. 상태만 남기고 **메시지 내용은 남기지 않음**. 300KB가 넘으면 뒤쪽 150KB만 남김
- 메뉴: `menuTemplate()` 하나를 트레이 우클릭 메뉴와 타이틀바 ⋯ 버튼이 같이 씀. 앱 메뉴바는 없음

## 외부 의존 (Instagram이 바꾸면 깨지는 곳)

- 받은편지함 데이터 경로 `/api/v1/direct_v2/inbox/` (2026-10 기준 404를 돌려줌, 화면 읽기로 대신 알리는 중)
- 목록 줄 DOM 판정 (`rowCandidates`, `preload.js`의 `isRow`): 높이 44–120px, 이미지가 있고 글자가 두 줄 이상
- 읽지 않음 판정: 미리보기 글자 굵기 600 이상
- 탭 제목 `(N)` 형식, 다크 모드 클래스 `__fb-dark-mode`
